# Teach-Dario 地图替换说明

## 替换内容

- 卷曲便便山、两圈盘山路、22 米高山顶平台与黄金马桶。
- 56–64 / 114–122 段的两座圆柱独木桥及各自直达山脚的滑道。
- 山体入口切口、三角网格碰撞、道路/桥梁/滑道碰撞和环境布置。
- 道路空间与高度投影、出生/重置朝向、11 个检查点和滑行状态。
- 17 件运行时 GLB、资源清单、生成工具与完整静态编辑预览。

保留 Teach-Dario 的第三人称视角、原角色美术、键鼠/手柄、镜头缩放、原地起身和登顶结算。没有迁移第一人称、便意系统或马桶 F 键交互。运行端口仍为 5190，工程与依赖保持本项目原配置。

## 滑道与存档

桥上自然跌落进入滑道后，放松身体并保留动态碰撞；重力、低摩擦及有限水平导向使角色连续滑向山脚。进入滑道立即清空检查点与本次登山进度，滑行中 R/Y 不返回桥前，暂停后继续滑行。实际接地后退出滑行，地面稳定时自动起身；可 R 回山脚入口。

新键 `baby-steps:save:poop-mountain:v1`，数据包括 `map: 'poop-mountain-v1'`。旧 `baby-steps:save:v1` 完全保留，新地图从山脚开始；旧成绩也不会被当作新地图最佳成绩。静音仍使用原设置键。

替换前相关模块、模型与原路线测试已备份至 `.runtime/map-before-poop-mountain/`。该目录被 Git 忽略，不进入生产包。

## 验证

- `npm test`：输入、身体物理、起身、存档、路线投影、桥面/滑道和起步回放。
- `npm run test:scene`：完整加载山体的世界，两座桥内外侧自然跌落并实际滑至山脚，检查连续位移、跌倒与检查点归零。
- `npm run test:browser`：第三人称键鼠、倾斜、抬落脚、镜头、起身暂停、重置和新地图续玩。
- `npm run test:assets`：资源校验、复用、缺失重试、编辑保留和第三人称网格避障。
- `npm run test:gamepad`：原手柄流程与缩放。
- `npm run build` / `npm run test:production`：类型与生产构建、生产公共界面和本地资源请求。

0–180 是盘山路线的设计进度，不等于弧长。地图几何与局部物理验证不代表整条盘山路已经人工通关；完整通关与长时间手感仍需试玩。
