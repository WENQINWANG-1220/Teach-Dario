# 物理重构验证说明

本版不是纯被动布娃娃。人物由 15 个动态刚体、14 个身体关节驱动，保留有限的承重和姿态辅助；鞋底另有仅在真实接触时启用的有限摩擦补偿，没有位置焊接或竖直锁定。辅助对应的载荷与 Rapier 实际接触载荷分别记录，不能把辅助力称为逐条肌肉的解剖仿真。

主要验收内容：

- 空中全身质心保持动量并按重力加速，键盘不能产生支撑；身体各部分始终动态。
- 关闭肌肉辅助后自然倒下，倒地标记不额外推人，不替换刚体，不重建腿长。
- 连续交替小步、四向身体倾斜和固定脚部目标；落脚动作本身不注入预设冲量。
- 起身检查落点与站立空间，保留关节和速度，以有限力连续收腿站起；四个朝向、阻挡中止与检查点中断均有测试。
- 木材浮力、石材下沉、空气阻力、道具碰撞传力及重置。
- GLB 文件回读、节点、材质编辑、加载失败重试、资源复用和实际子网格镜头避障。
- 浏览器真实鼠标左右键、优先规则、镜头冻结和恢复、Esc 暂停与锁定、续玩、1280×720 与 1920×1080 布局。

完整路线回放使用鼠标落点接口，并允许原地起身、R 等价的检查点重试，以及到新营地后重置站姿。它不跳过未到达的路段，不通过修改身体位置直接越过挑战。回放的保守步幅、等待与重试时间用于碰撞覆盖，不代表玩家最快通关时间。

环境的水体使用浸没体积近似；花草与旗布保留视觉表现，不模拟布料、植被破坏或流体网格。GLB 角色骨架版本改变，浏览器存档仍为原来的 v1。
