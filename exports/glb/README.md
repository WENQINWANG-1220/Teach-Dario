# Baby Steps GLB 美术资产约定

全部为自包含 glTF 2.0 二进制，Y 轴向上，1 单位 = 1 米。运行时读取 `public/models/`；`exports/glb/` 还包含完整静态预览与清单，供编辑参考。

## 人物骨架第 2 版

角色面向局部 −Z，约 1.8 米高。保留唯一的下列物理驱动节点：

- `Pelvis`、`Torso`、`Head`
- `Shoulder_L/R`、`Elbow_L/R`、`Hand_L/R`
- `Thigh_L/R`、`Shin_L/R`、`Shoe_L/R`

这 15 个节点均为模型根下的同级节点，运行时写入对应刚体的世界位置和旋转。`Leg_L/R` 是空的兼容命名容器，不承担腿的父变换。头、骨盆和手不再焊在躯干或前臂美术下。

美术放在驱动节点的子节点下，编辑子网格和材质不会被运行时覆盖。大小腿子网格标准长度 1、沿局部 Y、原点在段中点；驱动节点保留固定 `scale.y=0.43`，运行时不改变腿长。上臂、前臂、手和鞋的驱动原点也改为各自刚体中心。参考静止姿态以 `src/rig.ts` 为准：骨盆约 Y=0.99，躯干约 Y=1.29，头约 Y=1.64，鞋中心 Y=0.045。

模型不内嵌动画轨道；所有站立、倾斜、倒地和起身姿态由物理驱动并进行渲染插值。旧版只有躯干及 IK 腿节点的角色需要补齐新节点，加载器会检查并明确报告缺失的节点。

## 场景

`terrain-*.glb` 的原点在主体中心，路线参数缩放与摆放它们。圆木沿局部 Y 延伸，标准长 12 米；直径 0.90 / 0.76 米，桥梁旋转到水平。短圆木复用同一资产，独立缩放和动态质量。

树根、旗杆和路牌底部在原点；山体是半径 1、高 1.4 的低多边形山锥；岩石基础半径 1、Y 比例 0.7。`Sign_Board` 保留用于运行时文字，`Flag_Cloth` 保留用于轻微视觉摆动。`water.glb` 是单位 XZ 平面，不作为实体地板。

场景布局由 `src/art/layout.ts` 共享给游戏与导出器，包含确定性的松散道具摆放。完整场景预览包含人物站姿、道具初始姿态与烘焙路牌文字；不包含灯光、雾、物理过程或玩法 UI。

路线主体碰撞仍由 `src/terrain.ts` 的参数生成；树干、岩石、山体、路牌等从加载的 GLB 网格生成凸包，动态道具的密度、材质和浮力由环境物理模块控制。改变路线 GLB 的轮廓时需要同步路线碰撞参数；编辑环境网格会改变其凸包。镜头避障使用实际 GLB 子网格。

## 生成、替换与验证

```powershell
npm run assets:generate
npm run export:glb
```

工具临时启动本地 Vite，用已安装的 Chrome / Playwright 导出和回读验证，支持 Canvas 文字贴图。检查文件头、自包含资源、必要节点、有限包围盒及导出前后尺寸。普通构建不执行生成。

显式生成覆盖对应文件，手工编辑请先备份。编辑 `public/models/` 后刷新开发页即可查看；生产版重新构建，Windows 启动器会检测 `public/` 更新。不要编辑 `dist/models/` 副本。缺失文件、损坏 GLB 或缺失人物节点会显示文件名和重试按钮。
