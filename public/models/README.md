# Baby Steps GLB 美术资产约定

全部为自包含 glTF 2.0 二进制，Y 轴向上，1 单位 = 1 米。运行时读取 `public/models/`；`exports/glb/` 还包含完整静态预览与清单，供编辑参考。

## 人物骨架

当前角色是用户提供的 `Dariov2.glb`，包含 Mixamo 蒙皮骨骼及内嵌贴图。地图生成器直接复制原始人物文件，不重新生成或压缩人物。`src/dario.ts` 将骨盆、脊柱、头、双臂、双腿和双脚绑定到原有 15 个动态刚体；手指随父骨骼运动。加载时验证必要骨骼，`GLTFLoader` 会移除骨骼名中的冒号。

模型没有内嵌动作轨道。站立、迈步、失衡、倒地和起身都跟随真实物理姿态，保持现有控制；完整场景导出会摆成游戏参考站姿。旧 `hiker.glb` 与 `Dario.glb` 仅为历史文件，不在当前运行时清单中。

## 场景

`terrain-*.glb` 的原点在主体中心，路线参数缩放与摆放它们。圆木沿局部 Y 延伸，标准长 12 米；直径 0.90 / 0.76 米，桥梁旋转到水平。短圆木复用同一资产，独立缩放和动态质量。

树根、旗杆和路牌底部在原点；便便山体采用三层卷曲造型与尖顶，山脚有土丘和主题道具；岩石基础半径 1、Y 比例 0.7。`Sign_Board` 保留用于运行时文字，`Flag_Cloth` 保留用于轻微视觉摆动。`water.glb` 是单位 XZ 平面，不作为实体地板。

场景布局由 `src/art/layout.ts` 共享给游戏与导出器，包含确定性的松散道具摆放。完整场景预览包含人物站姿、道具初始姿态与烘焙路牌文字；不包含灯光、雾、物理过程或玩法 UI。

路线主体碰撞仍由 `src/terrain.ts` 的参数生成；树干、岩石、路牌等从加载的 GLB 网格生成凸包，山体使用与可见切口一致的三角网格，动态道具的密度、材质和浮力由环境物理模块控制。改变路线 GLB 的轮廓时需要同步路线碰撞参数；编辑环境网格会改变其凸包。镜头避障使用实际 GLB 子网格。

## 生成、替换与验证

```powershell
npm run assets:generate
npm run export:glb
```

工具临时启动本地 Vite，用已安装的 Chrome / Playwright 导出和回读验证，支持 Canvas 文字贴图。检查文件头、自包含资源、必要节点、有限包围盒及导出前后尺寸。普通构建不执行生成。

显式生成覆盖对应文件，手工编辑请先备份。编辑 `public/models/` 后刷新开发页即可查看；生产版重新构建，Windows 启动器会检测 `public/` 更新。不要编辑 `dist/models/` 副本。缺失文件、损坏 GLB 或缺失人物节点会显示文件名和重试按钮。
